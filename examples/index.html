Sortable columns
See the column API 
const duration = entry => entry.end == null ? 0 : entry.end - entry.start;
inspector.setColumns([
  ...defaultColumns.filter(c => c.id !== "status"),
  { id: "latency", label: "Latency", width: 180,
    render: entry => entry.end == null ? "In flight"
      : (entry.end - entry.start).toFixed(0) + " ms",
    sort: (a, b) => duration(a) - duration(b) },
]);
// Set sort: false to disable a column's sorter.
05 / APPLICATION DETAILS

A custom view, right where you need it.

Select any row to see the demo's custom summary on the right. Application events show their level and environment; requests show timing and payload size. The standard headers and body previews follow below.

Custom summary + default headers and body previews

See the details renderer API 
renderDetails(context) {
  const summary = context.document.createElement("section");
  summary.textContent = context.entry?.correlationId ?? "App summary";
  context.container.append(summary);
  context.renderDefault();
  return () => summary.remove();
}

View settings use localStorage. Retained capture history uses IndexedDB.

06 / CUSTOM STYLING

A different look. The same inspector.

Try Plum for warm violet surfaces, or Midnight for a complete dark theme, including content previews and Activity Insight badges. CSS variables cross the Shadow DOM boundary; a small override stylesheet adds the finishing touches. Your display preferences still apply, including in the details preview.

Default inspector styling

See the theme CSS 
[data-web-network-inspector][data-demo-effective="plum"] {
  --brand: #7c3aed;
  --brand-dark: #6024b5;
  --brand-soft: #efe5ff;
  --paper: #faf5ff;
  --ink: #312044;
}
/* Add inside inspector.root for internal selectors. */
:host([data-demo-effective="plum"]) .network-popup {
  border-radius: 18px;
}
/* Dark colors and token overrides also go into the details iframe. */
:host([data-demo-effective="dark"]) {
  color-scheme: dark;
  --panel: #141c2b;
  --ink: #e7edf8;
}
:host([data-demo-effective="dark"]) .network-json-string {
  color: #9be5c5;
}
