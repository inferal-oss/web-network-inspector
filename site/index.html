BUILT FOR THE SPACE BETWEEN

A request is only
part of the story.

Bring transport details and application context together, without building a debugging UI from scratch.

01

Inspect the full exchange

Fetch, XMLHttpRequest, WebSocket frames, and browser resource timings. Read retained headers and bodies as text, hex, or expandable JSON.

02

Put your own events on the map

A saved draft. A changed filter. A connection check. Record your own labels and payloads alongside the traffic they help explain.

03

Make room for your application

Add native controls, live status elements, and application-owned popups. The bar is an extension point, not a closed box.

A FEW LINES GO A LONG WAY

Small API.
Your vocabulary.

Keep the event types, controls, and content that make sense for your app. There’s no backend protocol to adopt.

Explore the API → 
inspector.recordEvent({
  type: 'document.saved',
  label: 'Saved a draft',
  correlationId: 'example-document',
  data: JSON.stringify({ revision: 3 }),
});
const status = document.createElement('span');
status.textContent = 'Ready';

inspector.addBarItem({
  id: 'connection-status',
  element: status,
});
inspector.openPopup({
  title: 'Connection details',
